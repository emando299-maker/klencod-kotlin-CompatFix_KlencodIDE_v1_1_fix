# CompatFix — المرحلة الأولى

مشروع Android/Kotlin قابل للاستيراد في KlencodIDE.

## ما يعمل حالياً
- اختيار APK عبر Storage Access Framework دون صلاحية تخزين عامة.
- قراءة package name وversion وminSdk وtargetSdk عبر PackageManager.
- فحص مجلدات `lib/<abi>/` داخل APK.
- مقارنة minSdk ومعماريات المكتبات مع جهاز التشغيل.
- عرض النتائج والتوصيات.
- تصدير نسخة من الملف الأصلي دون تعديل.

## إعداد KlencodIDE
1. فك ضغط CompatFix.zip.
2. افتح المجلد الذي يحتوي `settings.gradle.kts` كمشروع Gradle.
3. استخدم JDK 17 وAndroid SDK Platform 34 وBuild Tools المناسبة.
4. اسمح بتنزيل اعتماديات Gradle عند الطلب.
5. نفّذ Sync ثم Build APK.

## حدود مهمة
هذه نسخة تشخيص أولى وليست محرك إصلاح متقدماً مكتملاً. Android لا يوفر API عامة تسمح لتطبيق عادي بتعديل أي APK مثبت أو تجاوز قيود التوافق. التعديل الحقيقي يتطلب فك Manifest/DEX والموارد، إعادة البناء، ثم توقيع APK بمفتاح جديد. كما أن تغيير minSdk أو حذف required features لا يضيف APIs أو مكتبات ناقصة، وقد يجعل التطبيق يتعطل. لا يوجد ضمان أن كل تطبيق يمكن إصلاحه.

## مراحل التطوير التالية
1. محلل Manifest ثنائي وملفات split APK.
2. تحليل DEX وELF headers للمكتبات الأصلية.
3. تصنيف أسباب فشل التثبيت من سجل PackageInstaller.
4. محرك إصلاح محدود بقواعد آمنة وقابلة للتراجع.
5. إعادة البناء والتوقيع والتحقق من سلامة الناتج.
6. قائمة التطبيقات المثبتة عبر PackageManager مع مراعاة قيود رؤية الحزم.

## التحقق
لم يتم بناء المشروع أو تشغيله على جهاز فعلي ضمن هذه الجلسة. يجب عمل Gradle Sync وBuild واختبار APK قبل اعتبار النسخة صالحة.
